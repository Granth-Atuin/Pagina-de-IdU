# Austral Market · Panel de productos

Panel de gestión de productos para una tienda ficticia, hecho en React. Tiene una pantalla de inicio de sesión y una tabla de productos con alta, edición y baja.

## Funcionalidades

- Pantalla de login con opción para mostrar u ocultar la contraseña.
- Tabla de productos con nombre, categoría, precio, stock y estado.
- Formulario en ventana modal para crear y editar productos, con la imagen cargada por URL o subida desde la computadora.
- Validaciones: el precio y el stock no pueden ser negativos.

## Tecnologías

- React 18 y React Router
- Tailwind CSS
- Vite
- Íconos de Lucide

## Cómo correrlo

```bash
npm install
npm run dev
```

Después abrí http://localhost:5173.
